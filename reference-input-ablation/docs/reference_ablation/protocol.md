# 参考图输入消融：3案例配对预览

问题：智能体能查看原图、按原图写文字描述时，向生图工具开放原参考图输入是否影响结果？

从120组历史冲突条件中，按明确的实际传图日志筛选。可核验候选为E04、E35、E81、E95；E81存在离线复现异常，此次不选。固定选择E04人口构成、E35出生率、E95腾跃人物双系列趋势；不依据新结果换样。仅覆盖类别数和趋势形状，不覆盖数值范围，不代表120组总体。

每案例使用同一份冻结冲突数据、参考、简报、核心合同，重跑两个新会话。adaptive保留原流程自主决定是否传原参考图；textonly明确禁止把原参考图或其派生图作为生图输入。两组智能体均可先查看原图并写文字提示。共同可引用本会话未经修改的原始生成素材；共同禁止num_last_images_to_include和裁切/变换图作为生图输入以便核验，渲染器中的裁切与变换仍允许。实际输入选择须从调用记录核验，不能用自述替代。若adaptive也不传图，属于开放输入策略的实际结果，不强制补跑，不声称该配对存在实际传图差别。

GPT-6-Astra/max，35分钟/生成，最多3次内置生图、6次完整渲染；独立评审15分钟，技术失败最多补评1次。生成失败不重采样。生成、首末评审、第二评审全部共享最多3个模型会话。保留首个完整渲染尝试（包括失败）及最后有效图，不选最好候选。独立评分不反馈给生成器。

6个新生成条件均保留完整执行记录；所有可用首轮/最终图按120组实验的同一详细评审提示词与JSON schema独立盲评，同图复用评审。全部6张可用最终图再做第二次匿名评审，保留分歧，不覆盖首评。两个新组的评审程序相同；历史图及其详细评估仅作额外参照，不混入新配对统计。

数值、关键结构、当前意义、参考原意、小值可辨、共同主判据以及增加小值可辨的联合指标沿用既有定义。主通过率分母固定各组3个任务，技术异常、无图、非pass不计通过；另列有效配对与实际参考输入的核验状态。partial不等于严重失败。只有3组、每条件一次新生成，结果为描述性案例比较，不做总体显著性或因果强度推断。

公开独立网页保留参考图、历史图、两新条件所有有效轮次、同一数据与合同、独立评审、第二评审及实际传图核验。旧120组结果不修改。模型服务不可用或传图核验不足时，记录真实技术结果，不替换模型、不冒充实验完成。
